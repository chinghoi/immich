# Candidate validation

This is the optional EasyTier candidate branch. Existing installed Tailscale builds have not been replaced.

Implemented: exclusive selection, legacy preference migration, independent SDK adapters, Keychain configuration, loopback-only no-TUN core, provider-aware status and foreground limits.

Pending: cloud Rust tests, arm64 device/simulator framework builds, Flutter analysis/regressions, existing Tailscale simulator tests, full unsigned iOS app linkage, real iPhone install, Mac EasyTier peer provisioning, cellular TCP throughput and lifecycle tests. A PR or successful framework build is not device acceptance.
